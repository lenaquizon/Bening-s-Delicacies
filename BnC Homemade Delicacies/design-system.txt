3. TYPOGRAPHY
----------------------------------------------------

HEADING FONT
------------
Font Family:  "Playfair Display", serif
Source:       Google Fonts (https://fonts.google.com/specimen/Playfair+Display)
Weights:      600 (SemiBold), 700 (Bold)
Usage:        All headings, logo text, quotes/testimonials
Rationale:    Elegant serif that conveys tradition, warmth, and craftsmanship.
              Highly legible for older readers at display sizes.

BODY FONT
---------
Font Family:  "Lato", sans-serif
Source:       Google Fonts (https://fonts.google.com/specimen/Lato)
Weights:      400 (Regular), 600 (SemiBold), 700 (Bold)
Usage:        All body text, labels, buttons, captions, navigation
Rationale:    Clean, humanist sans-serif; highly readable at paragraph sizes.
              Pairs beautifully with Playfair Display.

6. ICONS & VISUAL LANGUAGE
----------------------------------------------------

- Icon style: Bespoke inline SVG line icons (Feather/Lucide style, 2px stroke, round caps/joins)
- No emojis used; pure SVG ensures consistent, professional rendering across all devices & OS platforms
- Use icons to SUPPLEMENT text labels — never replace them
  (accessibility: do not use color/icon alone to convey meaning)
- Feature & Value icons: 28×28px SVG inside 56×56px rounded container (color: #7B5C3A)
- Contact icons: 20×20px SVG inside 44×44px rounded container (color: #7B5C3A)
- Footer icons: 18×18px SVG (color: #E8C9A0) with text labels
- Checkmarks (Why Choose Us & Badges): Crisp SVG checkmarks inside #7B5C3A circles
- Navigation icons (mobile bottom bar): 22–24px SVG with text labels below


----------------------------------------------------
7. ACCESSIBILITY NOTES
----------------------------------------------------

- WCAG AA compliance throughout (see contrast ratios above)
- Minimum body text: 16px web + 16px mobile
- Minimum tap targets (mobile): 44×44px
- All form inputs have associated <label> elements
- Icon-only buttons have aria-label attributes
- Color is NEVER the sole indicator of meaning
  → Success states use ✓ icon + text
  → Active nav uses underline + color change
  → Errors would use icon + text (not just red color)
- Placeholder images annotated with alt-text comments in HTML
- Focus styles visible on all interactive elements
- Semantic HTML: <nav>, <main>, <section>, <article>, <footer>
- FAQ uses native <details>/<summary> for keyboard accessibility
- Mobile menu toggle: aria-expanded attribute updates on open/close

10. SPECIAL USE CASE: PASALUBONG FOR ABROAD & TRAVEL
----------------------------------------------------

A core customer behavior is ordering delicacies right before departing for
flights abroad (OFWs, Balikbayans, and travelers going to USA, Canada, Middle East,
Europe, and Asia).

Key requirements accommodated in the design:
- Luggage-friendly, durable sealed packaging
- Coordination of fresh cook times with flight schedules (e.g. NAIA departure)
- Espasol (20, 30, 50 pc boxes) and Cassava Cake (sealed trays) as primary travel items
- Direct customer guidance and travel-ready packaging info on the website
